# cacalc

Нативный дневник питания для iPhone на русском языке. Записывайте еду голосом
или вручную, проверяйте количество и сохраняйте приём. Приложение считает
калории, белки, жиры и углеводы по известным данным; еду без пищевой ценности
тоже можно записать.

Это развивающийся личный проект на SwiftUI для iOS 26+. Репозиторий содержит
исходники и инструменты разработчика. Готовой установки из App Store и общего
сервера аккаунтов здесь нет. Для установки своей сборки нужны Mac, Xcode
и собственная подпись Apple.

## Что умеет

- Дневник по дням, дневные цели КБЖУ, планы и подтверждённые приёмы пищи.
- Локальный поиск по базовому каталогу и собственным карточкам, сканер штрихкода.
- Распознавание речи на устройстве: Parakeet → локальный разбор еды и количества
  → редактируемый список → подтверждение.
- Независимые черновики продуктов, еды, рецептов и приготовлений.
- Рецепты, приготовленные партии, порции, остатки и история списаний.
- Виджеты КБЖУ и Live Activity диктовки.
- Необязательное чтение данных Apple Health: сон, активность и измерения.

Пример голосового ввода: «яблоко 150 грамм, дальше творог 200 грамм».
Проверьте названия, вес и привязку к карточкам перед сохранением. Голосовой
разбор использует ограниченную грамматику и может ошибаться.

## Данные и ограничения

Дневник хранится локально в SwiftData, базовый каталог — в отдельном SQLite.
Поиск и ручной ввод работают без сети после подготовки ресурсов. Голос требует
предварительной загрузки моделей. Текст прежних облачных диктовок может
отправляться в Polza по явному действию и с личным ключом; этот путь сохранён
для совместимости. Новая live-диктовка разбирается локально.

Неизвестное значение не равно нулю. Неполная пищевая ценность не даёт точного
остатка калорий. Обновление каталога не переписывает прошлые записи. План
не считается съеденным до подтверждения. Возраст приготовленной партии
показывает прошедшее время, а не оценку её годности.

Базовый каталог содержит выбранные продукты Matvaretabellen с русскими
названиями. Он не содержит всех покупок и штрихкодов. Веса моделей, базы,
личные записи, аудио и диагностические выгрузки в этот репозиторий не входят.
Сборка из чистой копии требует подготовки ресурсов; это не готовый бинарный релиз.

## Проверки

Без загрузки моделей и без сети, из корня проекта:

```sh
python3 -B -m unittest discover -s tests -v
python3 -B tools/check_usage_coverage.py
python3 -B tools/test_legacy_log_tools.py
python3 -B tools/check_public_release.py
```

На Mac с Xcode доступны проверки Swift; команды и требования к месту
описаны в [инструкции разработчика](docs/getting-started.md).
Синтетические тесты не являются оценкой точности произвольной речи.

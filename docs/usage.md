# Работа с приложением

## Первый запуск

Открывается «Дневник». В «Профиле» задайте свои дневные цели калорий, белков,
жиров и углеводов. Связь целей по формуле 4/9/4 необязательна; она не меняет
пищевую ценность продуктов. Сон и данные Health подключаются отдельно через
системный запрос разрешений. Приложение не записывает данные в Apple Health.

Вкладки: «Блюда», «Продукты», «Дневник», «Профиль». Дни можно перелистывать.
Изменение целей действует с текущего дня; история сохраняет прежние цели.

## Запись еды

Откройте добавление в дневнике. Найдите продукт, отсканируйте штрихкод либо
используйте микрофон. Скан ищет карточку и сам по себе не сохраняет съеденную еду.
Если карточка не найдена, заполните собственную либо сохраните неизвестную еду.
Результат голоса — предложение: проверьте каждую строку перед «Сохранить».

Для диктовки сначала загрузите предложенные приложением голосовые модели.
Загрузка использует интернет и занимает место; распознавание затем идёт на iPhone.
Для предсказуемого разбора называйте продукт и вес, разделяя позиции словом
«дальше» или паузой. Например: «яблоко 150 грамм, дальше творог 200 грамм».
Вес без слова «грамм» поддерживается в ограниченных случаях; явные единицы
проще проверить. Миллилитры не превращаются в граммы без известной плотности.

Неуверенное название, количество или совпадение исправьте в строке. Отсутствие
КБЖУ не запрещает сохранить факт еды. В сводке показывается известная часть;
неизвестное не прибавляется как ноль. Продукт в каталоге и факт его употребления
сохраняются отдельно.

Закрытие редактора сохраняет черновик. Продолжить можно соответствующую
незавершённую работу. Подтверждение сохраняет запись и закрывает её черновик;
при ошибке сохранения не удаляйте приложение и не очищайте его контейнер.

## Блюда и планы

Рецепт — состав будущего приготовления. Приготовленная партия — фактические
ингредиенты, измеренный готовый вес и число порций. Приготовить не значит съесть.
Списание остатка происходит вместе с подтверждённой записью дневника.

«Порция» найденной активной партии рассчитывается из оставшегося веса
и количества порций. Перед сохранением можно исправить граммы. Без найденной
партии приложение не должно придумывать массу. «Выбросить» архивирует остаток
с причиной и временем, сохраняя историю.

План не попадает в съеденное по наступлению времени. Действие «Съел»
подтверждает эпизод. Подсказки времени питания основаны на эвристике и истории.

## Виджеты и сохранность

Добавьте виджеты cacalc штатным меню iOS. Они получают отдельный снимок
агрегатов КБЖУ; система определяет время обновления.

Локальные данные не синхронизируются с общим сервером. Удаление приложения
может уничтожить дневник и записи голоса. Копия внутри контейнера не заменяет
проверенную внешнюю резервную копию. Не передавайте необработанные архивы,
логи или скриншоты с личными данными в публичные обсуждения.
